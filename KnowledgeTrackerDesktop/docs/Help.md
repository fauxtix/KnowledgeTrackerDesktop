# Ajuda - Knowledge Tracker

## 1. Introdução

O **Knowledge Tracker** é uma aplicação para registar, organizar e consultar a informação do seu conhecimento. Permite guardar registos com descrição, notas, etiquetas e categorias para encontrar rapidamente o que precisa.

## 2. Primeiros passos

1. **Abrir a aplicação** - Inicie o Knowledge Tracker. A janela principal apresenta a barra de navegação à esquerda e a área de conteúdo à direita.
2. **Explorar a Biblioteca** - A opção **Biblioteca** mostra os seus registos. É o ponto de partida para consultar e gerir o seu conhecimento.
3. **Ver Estatísticas** - A opção **Estatísticas** apresenta informação agregada sobre os registos existentes.
4. **Alterar idioma** - Pode mudar entre Português e Inglês através dos botões no fundo da barra de navegação.

## 3. Principais funcionalidades

### 3.1 Biblioteca

Na vista **Biblioteca** consegue:

- **Visualizar registos** - Lista todos os registos guardados com a informação principal.
- **Criar registos** - Adicionar novo conhecimento à sua biblioteca.
- **Editar registos** - Atualizar a informação de registos existentes.
- **Eliminar registos** - Remover registos que já não são necessários.
- **Pesquisar e filtrar** - Localizar rapidamente registos por palavras-chave, categoria ou etiquetas.

### 3.2 Editor de registos

Ao criar ou editar um registo, tem acesso a campos para organizar a informação:

- **Título / Informação principal** - Identificação clara do registo.
- **Descrição/Notas** - Espaço para detalhar o conhecimento com contexto.
- **Categoria** - Agrupar registos por tema.
- **Etiquetas (Tags)** - Adicionar etiquetas para facilitar a pesquisa transversal.
- **Data/Metadados** - Informação adicional associada ao registo.

### 3.3 Estatísticas

A vista **Estatísticas** permite ter uma visão geral da sua biblioteca, incluindo contagens por categoria/etiquetas e distribuição dos registos.

### 3.4 Navegação

- **Barra de navegação lateral** - Aceda rapidamente à Biblioteca e às Estatísticas.
- **Cabeçalho** - Mostra o título da vista atual.
- **Ações do cabeçalho** - Botões contextuais conforme a vista onde se encontra.

## 4. Dicas e truques

- **Mantenha organizado** - Utilize categorias e etiquetas de forma consistente para facilitar a pesquisa.
- **Seja descritivo** - Títulos claros ajudam a encontrar registos rapidamente.
- **Use a pesquisa** - Em vez de percorrer toda a lista, utilize os filtros/pesquisa para localizar informação específica.
- **Atalho para ajuda** - Prima **F1** em qualquer altura para abrir esta janela de ajuda (ou clique em **Ajuda** no menu lateral).

## 5. Perguntas frequentes (FAQ)

**P: Como altero o idioma da aplicação?**  
R: Utilize os botões PT/EN no fundo da barra de navegação lateral.

**P: Como adiciono um novo registo?**  
R: Na vista Biblioteca, utilize a ação correspondente para criar um novo registo (botão/ação no cabeçalho ou conforme apresentado na interface).

**P: Os meus dados ficam onde?**  
R: A aplicação utiliza uma base de dados local (`knowledge.db3`) na pasta da aplicação/configuração conforme o ambiente de execução.

**P: Posso abrir esta ajuda sem usar o menu?**  
R: Sim, basta premir **F1**.
